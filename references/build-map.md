# 生成交互地图（可选交付，推荐）

在完成「成文」（Step 8）与「导出 PDF」（Step 9）后，可再生成一张手机友好的交互地图页，
与 PDF 一并交付。地图只做**行程可视化与分享**，不替代 PDF 的完整攻略内容。

## 何时生成

- 默认生成：客户要「行程地图 / 发手机看 / 分享给同伴」或任何多人出行场景。
- 客户只要 PDF 时跳过本步；跨多日、多城市的行程都建议生成。

## 数据来源（重要：只复用已核实数据）

地图数据**必须全部来自本流程已核实的成果**（Step 1-8），不得在地图里新造任何价格/评分/门票/时间：

| 字段 | 来源 |
|---|---|
| 酒店（HOTEL） | Step 5 住宿汇总的首选酒店 |
| 每日景点/地点 | Step 2/3/4 行程与门票清单 |
| 餐厅 | Step 6 每日三餐表（主推 + 备选，备选 `time` 填 `—`） |
| 航班/交通/预算 | Step 2 远程交通、Step 8 预算章节 |
| 支付提醒 | 行前清单/风险章节里的现金、预约、限流提示 |

## 坐标：WGS84 与 GCJ-02（关键坑）

- 地图底图（Leaflet/OSM/cartocdn）使用 **WGS84** 坐标。
- 高德/百度网页上查到的坐标是 **GCJ-02**（火星坐标），直接填会导致点位偏移约 500 米。
- **处理方式**：在 `map_data.json` 顶层写 `"coords": "gcj02"`，脚本会自动转换；从 OSM 等 WGS84 源取数时写 `"coords": "wgs84"`（默认）。
- 酒店与每个地点都要有坐标；没有坐标的地点不放进地图（但可保留在 PDF）。

## 工作流

1. 用已核实的行程数据编写 `map_data.json`（schema 见下方与 `examples/map_data.sample.json`）。
2. 运行生成脚本（优先 Codex 运行时 Python）：

```bash
python scripts/build_map.py map_data.json outputs/trip_map.html
```

3. 交付前检查（详见「验证清单」），确认地图页在手机浏览器打开正常、数据与 PDF 一致。

## map_data.json 结构

```json
{
  "title": "北疆金秋 9 日行程地图",
  "subtitle": "9.18–9.27 · 3 人 · 乌鲁木齐进出",
  "description": "行程预览与手机分享用交互地图（含导航/点评/小红书直达）",
  "coords": "wgs84",
  "hotel": { "name": "如家素柏·云酒店(机场店)", "lat": 43.905, "lng": 87.48 },
  "info": {
    "hotel": "如家素柏·云酒店(机场店)",
    "flight": "9.18 CZ6901 北京→乌鲁木齐",
    "transit": "自驾 + 高德实测已核对",
    "budget": "人均约 ¥6,800"
  },
  "pay_summary": [
    { "title": "现金", "text": "部分景区/县城只收现金，备少量现金", "warn": true }
  ],
  "days": [
    {
      "id": 1, "label": "D1", "date": "9.18（周五）", "title": "抵达 · 市区休整",
      "color": "#ff9500",
      "locations": [
        {
          "name": "新疆国际大巴扎", "lat": 43.783, "lng": 87.62,
          "type": "spot", "time": "16:00",
          "desc": "大巴扎逛吃，感受民族风情",
          "budget": "免费",
          "detail": "地铁 1 号线二道桥站直达\n晚上 8 点后部分摊位收摊",
          "pay": { "alipay": 1, "wechat": 1, "cash": 1 },
          "xhsKeyword": "新疆国际大巴扎",
          "dianpingKeyword": "新疆国际大巴扎",
          "reserve": ""
        }
      ]
    }
  ]
}
```

### 字段说明

- 顶层 `coords`：`"wgs84"`（默认）或 `"gcj02"`（高德/百度取数时）。
- `hotel`：必填，地图默认中心；不填则用中国中部坐标兜底。
- `info`：总览页四张信息卡（酒店 / 航班进出 / 交通 / 预估费用）。
- `pay_summary`：总览页「支付提醒」卡片，`warn: true` 显示红色警示，否则绿色。
- `days[].color`：该日地图点位与连线颜色（可复用模板默认色板）。
- `locations[].type`：`food`（餐）/ `spot`（景）/ `drink`（饮）/ `hotel`（酒店）/ `transport`（交通）。
- `locations[].time`：`16:00` 表示正式行程点；`—` 表示备选（渲染进「备选」区，不进主线连线）。
- `locations[].pay`：`1` 支持 / `0.5` 部分支持 / 省略不显示；键：`cash`、`card`、`alipay`、`wechat`。
- `xhsKeyword` / `dianpingKeyword`：小红书/大众点评搜索词，默认取店名（自动去除括号）；无需填真实链接。
- `reserve`：预约链接（如官方小程序/携程），可留空字符串。
- `detail`：卡片内可展开的补充说明，用 `\n` 换行。

## 验证清单（交付前）

- [ ] `python scripts/build_map.py` 正常输出且 QA 行显示天数/地点数正确。
- [ ] 打开生成的 HTML：总览页 4 张信息卡、行程概览列表、支付提醒、图例齐全。
- [ ] 切换到每一天：地图点位、连线、时间轴卡片与 PDF 行程一致（地名/时间/顺序）。
- [ ] 高德/百度取数的坐标已声明 `"coords": "gcj02"`（否则点位会偏 500 米）。
- [ ] 所有价格/门票/时间与 PDF 一致，没有新造数据。
- [ ] 手机浏览器（或微信内打开）验证：导航按钮能拉起高德/地图 App，点评/小红书按钮可用。
- [ ] 文件命名 `trip_map.html`（或 `<目的地>_map.html`），与 PDF 一起放客户 `outputs/` 目录。
