# 餐厅评分与人均核实（大众点评）

目标：为每日三餐给出**具体店名 + 评分/评价数 + 人均**，以**大众点评登录实测**为准，参考真实评价，不要太贵，且时间上赶得及。

## 0. 登录前置（必须先做）

- 大众点评 PC 端**未登录基本无法搜索取数**，必须让客户在**应用内浏览器（侧边栏）**扫码登录。
- **登录应在主流程 Step 0 完成**（策划开始前引导），此处只复用已登录会话；不要在出完行程后才补登录。
- 登录页：`https://account.dianping.com/pclogin?redirUrl=https%3A%2F%2Fwww.dianping.com%2F`
- 页面显示「APP扫码登录」；若二维码显示「已失效」，点击「请点击刷新」再让客户扫。
- 客户扫码登录后跳回 dianping.com，右上角出现用户名/头像即成功。
- **遇到登录墙/风控验证码时停下来，请客户在侧边栏完成登录/验证；未经确认不代解验证码。**

## 1. 定位城市并拿到城市 ID（关键步骤）

- 大众点评 PC 首页可能是精简页，直接访问城市页：`https://www.dianping.com/<拼音>`，如 `wulumuqi`、`aletaidiqu`（阿勒泰地区）、`aletai`（阿勒泰市）、`boertala`（博尔塔拉）、`kelamayi`（克拉玛依）。
- 城市 ID 从页面 HTML 里提取：正则 `cityId["']?\s*[:=]\s*["']?(\d+)`（例：乌鲁木齐=325、阿勒泰地区=338、阿勒泰市=2275、博尔塔拉=330、克拉玛依=326）。
- 县城/乡镇通常归在上一级地区城市下（如布尔津/禾木/白哈巴在「阿勒泰地区」下）。

## 2. 大众点评搜索餐厅

- 直接访问搜索 URL（比页面内点搜索按钮稳定）：

```
https://www.dianping.com/search/keyword/{cityId}/0_{关键词(URL编码)}
```

- 从结果正文提取：店名、**评价数**、**人均**、菜系、所在区/县。
- 关键词用店名核心词（如「马风花大盘鸡」「禾田烤包子」「山间小味」）。

## 3. 说明：不做美团交叉

- **美团网页版已不可用**（无搜索入口），本 Skill 不再承诺「大众点评+美团」交叉验证；餐厅数据一律以**大众点评登录实测**为唯一准。
- 如需第二来源，可叠加 Trip.com/携程美食/小红书 的公开评价作补充参考，但必须标注平台来源，不得与点评数据混写。

## 4. 判断与记录

- 优先选：评价数多（数百条以上）且人均符合预算的店；景区内人均比市区贵 ¥10-30 属正常。
- 找不到/未收录的店（例如某些网红店只在小红书/携程美食有）→ 记录为「第三方源（携程美食/Trip.com 评分）」或干脆换有评价的替代店。
- 记录：店名 | 城市/位置 | 评价数/人均（注明平台） | 推荐菜 | 时间衔接提示（营业时间、饭点排队、是否需订座）。
- 热门店（土火锅、剧组打卡店）提示提前电话订座。

## 5. 输出

- 汇总成每日三餐表：`日期 | 餐次 | 推荐店(城市/位置) | 评分参考(平台) | 人均 | 点单建议 | 时间衔接提示`，含备选行。
- 标注「大众点评实测（日期）」；提醒用户出行前可在大众点评 App 复核营业状态。
