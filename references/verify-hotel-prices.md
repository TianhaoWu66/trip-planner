# 酒店价格核实（携程 + 飞猪实测价）

目标：为「N 人住 1 间」的真实行程日期拿到**当日可订的含税价格**，并在**携程与飞猪两家交叉核对**，给每个晚上筛选至少 1-2 个住宿点（一般实惠档）。

## 0. 登录前置（必须先做）

- 让客户在**应用内浏览器（侧边栏）**打开携程并登录（右上角「登录」→ 扫码登录，用携程 App 扫）；需要时同样登录飞猪。
- **登录页由 AI 直接打开**：Step 0 时用侧边栏新建标签页直接打开携程/飞猪页面并停在登录入口，让二维码可见；不要只发一句「请先登录」让客户自己找入口。
- **登录应在主流程 Step 0 完成**（策划开始前引导），此处只复用已登录会话；不要在出完行程后才补登录。
- 未登录也能看部分列表价，但**优惠价/登录价拿不到，且查询量大容易被风控**；必须先请客户登录再取数。
- 复用已登录会话；不要代为下单、改单、领券或付款——只读价格。
- **遇到登录墙/风控验证码时停下来，请客户在侧边栏完成登录/验证；未经确认不代解验证码。**

## 1. 准备

- 明确：入住/退房日期、人数（成人/儿童）、城市与商圈（景区内还是市区）、预算档位。
- 携程酒店列表 URL 模板：

```
https://hotels.ctrip.com/hotels/list/?checkin=YYYY/MM/DD&checkout=YYYY/MM/DD&adult=3&child=0&cityName=<城市>&cityId=<城市ID>&v2_mod=40&v2_version=E
```

- 城市 ID 可直接从携程搜索框/城市列表页获得；不填 cityId 只填 cityName 多数也能搜到。
- 飞猪：`https://hotel.fliggy.com/`（或 App）按相同日期/人数搜索。

## 2. 携程筛选与记录

- 勾选「3 成人」或按实际人数；筛选条件按需（价格升序、品牌、位置）。
- 对每个候选酒店记录：**店名、房型、含税价、床型（是否 3 张床/大床+单人）、早餐是否含、可否免费取消、是否有房**。
- 标注「门市价/优惠价」两种口径（如 ¥2,099 优惠 ¥1,865），并记录抓取日期。
- 无房的标注「当日已无房」，并换备选。

## 3. 飞猪交叉核对

- 对每晚的首选酒店，在飞猪用相同日期/人数再查一次：价格是否一致、是否有房、是否更便宜。
- 携程/飞猪价格有差异属正常（促销渠道不同），记录两家价格；**同一晚给 2 个以上候选：首选 + 备选，说明 3 人入住床型提示与在哪家订更划算**。
- **飞猪网页版搜索会弹新标签页/新页面**：从 www.fliggy.com/jiudian/ 填好城市/日期后点「搜索酒店」，结果在**新标签页**（hotel.fliggy.com/hotel_list3.htm）打开，不是当前页跳转；不要反复点击搜索按钮，等待新标签出现后认领并读取结果。
- 在飞猪结果页用关键词再搜（青旅名/民宿名/商圈），同样会弹出或刷新新页；以 URL 中 `keywords=` 参数确认条件是否生效。
- 青旅/民宿的**床位房**在飞猪网页版常显示「暂无报价」或未收录（携程有价）——属正常，如实标注两家差异，并提示客户用飞猪 App 复核。
- 景区（如喀纳斯/禾木/白哈巴）金秋房源少且贵，任何一家看到可订就提示用户尽快锁房。

## 4. 输出

- 汇总成表：`晚 | 地点 | 首选(酒店·房型·携程价/飞猪价) | 备选 | 3人入住提示`，注明「携程/飞猪实测价 + 抓取日期」。
- 若某晚实在订不到景区内，给出市区/景区门口替代并说明代价（往返时间）。
