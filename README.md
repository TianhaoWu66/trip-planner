# Trip Planner

> 面向**国内风景路线**的 AI 行程规划 Skill：**先引导登录** → 确认需求 → 查交通/门票 → 实测房价/餐厅 → 出攻略（Markdown + PDF）；可行性分析仅在你自带计划时做。
> 数据全部带**来源和核实日期**。

## ⚠️ 使用前必读：需要你配合「登录 + 人机验证」

这个 Skill 要拿到**真实数据**（酒店实价、餐厅评分、路线里程），必须登录平台；平台检测到批量查询时会弹人机验证。**这些只能由你（用户）完成，AI 不会代做、也不会硬闯。**

| 场景 | 你会看到 | 你需要做什么 |
|---|---|---|
| 查酒店价格 | AI 在侧边栏打开**携程**，提示你登录 | 打开携程 App **扫码登录**（或账号登录） |
| 查餐厅评分 | AI 在侧边栏打开**大众点评**，提示你登录 | 打开大众点评 App **扫码登录** |
| 查酒店比价（可选） | AI 在侧边栏打开**飞猪**，提示你登录 | 打开淘宝/支付宝 App **扫码登录**（飞猪=淘宝账号体系） |
| 查路线/公交 | AI 在侧边栏打开**高德地图**，提示你登录 | 打开高德 App **扫码登录**（可与上面几家一起登） |
| 出现验证码 | 侧边栏弹出**滑块/点选/短信验证**或风控页 | **由你亲手完成验证**，完成后告诉 AI「好了」 |
| 二维码失效 | 点评登录页显示「二维码已失效」 | 点「**请点击刷新**」再扫 |

> AI 会**每次重新打开侧边栏页面**（标签页跨轮会被清理，属正常），并在遇到登录/验证时停下来等你。**不要跳过登录**——未登录拿到的价格和评分不真实、不全。

## ✨ 亮点

- **数据源优先，不凭记忆编**：门票/价格/里程/评分必须注明来源（官方小程序 / 12306 / 航司 / 携程 / 飞猪 / 大众点评 / 高德网页版实测），查不到就标「待核实」
- **住宿比价、餐厅点评实测**：住宿在「携程 + 飞猪」比价；餐厅评分/人均以**大众点评登录实测**为准（美团网页版不可用，不做美团交叉）；所有数字标注平台与核实日期
- **路线用高德实测**：起终点用精确 POI（酒店/餐厅/景区），免 Key 免认证，直接调高德网页版 `ditu.amap.com/dir` 拿里程/用时/途经；**公共交通（公交/地铁/BRT/火车混合）也能查**：时长/步行/票价/线路名 + 打车参考价
- **登录与人机验证交给使用者**：AI 停下请你完成，绝不硬闯
- **一键出稿**：Markdown 攻略 + A4 PDF（内置转换脚本），章节齐全

## 🎯 这个 Skill 的优势

| 对比 | 直接问 AI / 通用攻略 | 本 Skill |
|---|---|---|
| 酒店价格 | 凭印象或过期信息 | **携程 + 飞猪双平台实测当日含税价**，标注「抓取日期」 |
| 餐厅推荐 | 名气/网红堆砌 | **大众点评登录实测评价数与人均**，附时间衔接，不绕路 |
| 路线车程 | 拍脑袋估计 | **高德网页版实测**：精确 POI 起终点 → 真实里程/用时/途经/通行窗口 |
| 门票预约 | 可能过时或编造 | 每条带**来源渠道 + 核实日期**，查不到就标「待核实」，绝不瞎编 |
| 贴合你的航班 | 通用模板 | 按你**已确认的航班/日期/人数/预算**排，衔接余量逐段验证 |
| 出品 | 一段文字 | **12 章节 Markdown + A4 PDF**，含预约清单/预算/行前清单/用餐表 |
| 合规安全 | 可能硬闯验证码 | 登录与验证**一律交给你**，不代解、不绕过、不触发风控 |

**核心优势一句话：真实数据 + 可溯源 + 免认证也能跑 + 按你的行程定制。**

- ✅ **免 Key 免认证**：路线用高德网页版实测，不需要地图开放平台实名认证（对比同类 Skill 强制要求高德 MCP + 认证）
- ✅ **只读不越权**：只查价格和评价，绝不下单、不改单、不付款
- ✅ **可迭代**：对话里改景点、加一天、换酒店 → 重新核对、重新出稿
- ✅ **家庭/朋友小团友好**：支持 N 人 1 间、实惠档、床型提示（三人间/大床+单人等）

## 📖 怎么用（三步）

### 第 1 步：安装

```bash
# 以 Codex 为例，克隆到个人 skills 目录（其他客户端见下方说明）
git clone https://github.com/<你的用户名>/<你的仓库>.git "$HOME/.codex/skills/trip-planner"
```

重启你的 AI 客户端（Codex / Claude Code / Cursor 等）。

### 第 2 步：说出你的需求

直接说人话，例如：

```
帮我制定北疆旅游攻略，9.18–9.27，3个人，风景漂亮一点
计划一次川西自驾，10月，2个人
做个云南行程，预算中等
```

建议一次说清：**目的地 / 日期 / 人数 / 预算 / 想看什么**。没有想法也行——AI 会先收集攻略给你候选。

### 第 3 步：跟着 AI 走，按提示配合

典型流程（AI 会一步步来，需要你时一定会停下来叫你）：

1. **AI 在侧边栏直接打开 携程 + 大众点评 + 高德 页面**（需要时也打开飞猪）→ 你在弹出的页面**逐一扫码登录** → 你说「好了」；登录是策划第 0 步，动手取数前先搞定
2. AI 确认日期、人数、预算、想去哪 → 你确认或调整
3. AI 查远程交通（12306/航司）、规划路线（高德实测）→ 无需你操作
4. AI 核住宿：携程 + 飞猪比价 → 无需你操作（如果弹验证码，你完成）
5. AI 核餐厅：大众点评实测 → 无需你操作
6. 遇到任何**验证码/登录墙**：AI 停下 → 你完成 → 说「好了」
7. AI 出攻略（Markdown + PDF），提醒你紧急预订（内段机票、景区住宿、门票）

> 对话示例：
> ```
> 你：帮我制定北疆旅游攻略，9.18–9.27，3个人
> AI：好。我已把 **携程 / 大众点评 / 高德** 的登录页打开在侧边栏（需要时还有飞猪），请逐一扫码登录（我要查真实房价、餐厅评分和路线），登录好说一声
> 你：好了
> AI：收到。先确认：机场往返已定吗？预算大概多少？……
> AI：9.18 如家素柏·云酒店(机场店) 标准三人间 ¥330 含早可退……
> ```

## 🧭 工作流（11 步）

1. **策划前先引导登录（Step 0，硬性前置）**：动手取数前，先在侧边栏**直接打开 携程/大众点评/高德（需要时含飞猪）登录页**让客户一次性扫码；未登录不开始取数
2. **确定时间与景点清单**：客户想法优先；没有就用浏览器收集小红书/马蜂窝等攻略给出候选。**自带计划才做可行性分析；从零策划直接出路线图**
3. **远程交通**：12306（铁路）或各航司官网（航班），机场更名、航班号、衔接余量逐一核对
4. **城际与区内交通**：高德网页版/MCP 实测每段车程（精确 POI 起终点），标注里程、用时、途经、通行窗口（如阿禾公路 9:30–15:00、限 7 座）；**公共交通切「坐公交」模式查**（公交/地铁/BRT 方案+票价），城际火车以 12306 为准
5. **门票与预约**：每一条带来源渠道 + 核实日期，查不到标「待核实」
6. **住宿**：携程 + 飞猪实测价，每晚至少首选 + 备选，注明床型/含早/可退
7. **就餐**：大众点评登录实测评分人均（美团网页版不可用，不做美团交叉），产出每日三餐表（含备选与时间衔接）
8. **天气**：按目的地与日期查温度/降水/风
9. **成文**：12 章节 Markdown，所有数据标来源与日期；第 1 章按场景切换（自带计划=可行性速览 / 从零策划=行程总览）
10. **导出**：`python scripts/build_pdf.py input.md output.pdf`（Edge headless + 页数质检）
11. **交付**：MD + PDF，提醒紧急预订（内段航班、景区住宿、门票）

## 🔌 可选增强：地图 MCP

默认用**高德网页版（免 Key）**查路线；想更自动化可接高德/百度地图 MCP（需在高德/百度开放平台实名认证并申请自己的 Key，**每人用自己的 Key，勿写死共享**）。

- 高德 MCP（推荐）：`https://mcp.amap.com/mcp?key=你的Key`（Streamable HTTP）
- 百度 MCP：`https://mcp.map.baidu.com/mcp?ak=你的AK`（Streamable HTTP）
- 无 Key 时自动降级为高德网页版 + 参考值（标「待核实」）
