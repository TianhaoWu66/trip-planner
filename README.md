# Trip Planner

> 国内风景多日游的**可预订级攻略**：真实数据 + 可溯源 + 免认证也能跑。
> 产出：**12 章节攻略（Markdown + PDF）**，可选加一份**手机交互地图**（分享给同伴直接在手机上查看/导航）。

## 它能给你什么

- **真实的酒店价格**：携程 + 飞猪按你的日期/人数实测当日含税价，每晚给首选 + 备选
- **靠谱的餐厅**：大众点评登录实测评分/评价数/人均，附时间衔接，不绕路
- **实测的车程路线**：高德实测里程/用时/途经，公共交通（公交/地铁/BRT）也能查
- **可溯源的预约购票清单**：每条带来源渠道 + 核实日期，查不到就标「待核实」，绝不编造
- **完整攻略文档**：预约清单、费用预算、行前准备、每日三餐、天气穿衣，12 章齐全
- **手机地图（可选）**：行程一键生成交互地图，含导航、大众点评/小红书直达按钮，发链接给同伴即看即用

## ⚠️ 使用前必读：需要你配合「登录 + 人机验证」

要拿到真实数据（酒店实价、餐厅评分、路线里程），需要你在**应用内浏览器**里扫码登录几个平台；遇到验证码时由你亲手完成，AI 不会代做、也不会硬闯。

| 场景 | 你会看到 | 你需要做什么 |
|---|---|---|
| 查酒店价格 | 打开**携程**，提示你登录 | 携程 App 扫码登录 |
| 查餐厅评分 | 打开**大众点评**，提示你登录 | 大众点评 App 扫码登录 |
| 查酒店比价（可选） | 打开**飞猪**，提示你登录 | 淘宝/支付宝 App 扫码登录 |
| 查路线/公交 | 打开**高德地图**，提示你登录 | 高德 App 扫码登录（可与上面一起） |
| 出现验证码 | 滑块/点选/短信验证或风控页 | **你亲手完成**，完成后说「好了」 |
| 二维码失效 | 点评登录页显示「已失效」 | 点「请点击刷新」再扫 |

> 登录是策划的第 0 步：AI 会把登录页直接打开在侧边栏，你逐一扫码即可。**不要跳过登录**——未登录拿到的价格和评分不真实。

## 怎么用（三步）

1. **安装**：把本仓库克隆到你的 AI 客户端的 skills 目录（如 `~/.codex/skills/trip-planner`），重启客户端。
2. **说出需求**：直接说人话，例如「帮我制定北疆旅游攻略，9.18–9.27，3 个人」「做个云南行程，预算中等」。一次说清目的地 / 日期 / 人数 / 预算 / 想看什么；没想法也行，AI 会先给候选。
3. **跟着走**：AI 打开登录页 → 你扫码登录 → 确认行程 → AI 核实交通/住宿/餐厅 → 出攻略（PDF + 可选地图），并提醒你紧急预订（内段航班、景区住宿、门票）。

## 说明

- 所有价格/评分/里程均为**抓取当日实测值**，随季节与库存浮动，预订前以平台实时价格为准。
- 本 Skill 只读取价格与评价，**不会代为下单、改单或付款**。
